# 최근경제동향 작성 도우미

재정경제부 경제분석과가 매달 작성하는 「최근경제동향」을 돕는 웹 도구입니다. 국가데이터처의 「산업활동동향」 보도자료(PDF)를 올리면 핵심 수치를 뽑아 표로 보여 주고, 원자료와 맞는지 검증하고, 담당자가 쓴 작성본의 숫자를 대조하고, 종합평가 초안까지 만들어 줍니다.

> 비공식 보조 도구입니다. 재정경제부나 국가데이터처의 공식 서비스가 아닙니다. 초안은 담당자가 확인하기 전에는 확정본이 아닙니다.

## 만든 이유

매달 산업활동동향 수치를 한글 문서에 손으로 옮기고 종합평가 문장까지 직접 쓰느라 시간이 많이 들고(약 3일), 숫자를 잘못 옮겨도 걸러 줄 장치가 없었습니다. 이 도구는 반복되는 수작업을 줄이고 수치 오기입을 막는 것이 목표입니다. 자세한 배경은 [PRD.md](PRD.md)에 있습니다.

## 하는 일

화면 한 장에서 위에서 아래로 다섯 단계가 이어집니다.

1. **자료 올리기**: 산업활동동향 보도자료 PDF를 고릅니다. PDF는 내 컴퓨터(브라우저) 안에서만 읽고, 파일 자체는 서버로 보내지 않습니다.
2. **추출한 수치**: 전산업생산·소매판매·설비투자의 전월비·전년동월비와 경기동행·선행지수 전월차, 모두 8개를 표로 보여 줍니다. AI가 읽은 값은 AI 없이 보도자료의 다른 표·본문 문장과 다시 맞춰 보는 "교차 확인" 열이 붙고, 불일치한 값은 초안에 쓰지 않습니다. 못 찾은 칸은 비워 두고 직접 입력할 수 있습니다. 추출이 통째로 실패해도 빈 표가 열립니다. 그 아래에 지표별 **그래프**(최근 다섯 달 막대·선)가 나오고 PNG로 저장할 수 있습니다.
3. **오류 검증 결과**: 원자료와 다른 값이 있으면 어디가 다른지, 몇 쪽 어느 표인지 함께 보여 줍니다.
4. **작성본 대조**: 한글에 쓴 작성본을 붙여 넣으면 지표별 숫자를 원자료와 맞춰 일치·불일치·확인 불가로 알려 줍니다. 이 단계는 AI 없이 브라우저 안의 코드로만 처리하며, 작성본은 서버나 AI로 보내지 않고 저장하지 않습니다.
5. **종합평가 초안**: 검증을 통과한 수치만으로 AI가 문장 초안을 씁니다. AI가 쓴 글에 보내지 않은 숫자가 섞이면 받지 않습니다. 복사하면 맨 위에 `[초안 — 담당자 확인 전]` 표시가 붙습니다.

**부록 수출입 표 채우기 (추가 기능)**: 맨 아래 칸에 산업통상부 「수출입동향」 보도자료 PDF를 올리면 최근경제동향 부록 수출입(통관)·지역별(미국·일본·중국·EU) 표의 새 달 한 줄을 채워 줍니다. AI 없이 브라우저 안의 코드로만 읽고, 서로 다른 표와 맞지 않는 칸은 비워 둡니다. 한국은행(ECOS) 자료를 쓰는 부록 표는 아직 지원하지 않습니다.

## 기술

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- PDF 글자 꺼내기: `unpdf` (브라우저에서 실행)
- AI: OpenAI (기본 모델 `gpt-5.4-mini`, 서버 코드에서만 호출)
- 입력 검사: `zod` · 시험: `vitest` (시험 190개)
- 배포: Vercel

## 직접 실행하기

```bash
npm install
```

프로젝트 폴더에 `.env` 파일을 만들고 OpenAI 키를 넣습니다. (`.env`는 `.gitignore`에 등록되어 있어 저장소에 올라가지 않습니다.)

```bash
OPENAI_API_KEY=여기에_키를_넣으세요
APP_PASSWORD=여기에_사용할_비밀번호
```

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 시험은 `npm test`, 검사는 `npm run lint`와 `npm run build`로 합니다.

## 보안과 개인정보

- 비밀 키는 서버에서만 읽고 화면 코드와 저장소에 넣지 않습니다.
- 서버는 받은 글을 저장하거나 기록(로그)에 남기지 않습니다.
- 같은 주소에서 1분에 수치 추출 5번·초안 10번까지만 받고, JSON이 아닌 요청과 다른 사이트에서 온 요청은 거절합니다.
- 알려진 한계: PDF **전체 글자**가 서버로 전송되므로 표지의 담당자 연락처가 포함될 수 있습니다. 표 쪽만 먼저 골라 보내는 개선은 이후 과제입니다.

- 지수로 증감률을 다시 계산하는 검증 (지수 값을 아직 가져오지 않음)
- 글자 하나하나까지 비교하는 검증 (지금은 숫자 값으로 비교)

## 주의

- 외부 AI 서비스에 자료를 보내므로, 실제 업무에 쓰기 전에 부서의 정보보안 지침을 확인해야 합니다.
- 화면의 재정경제부 로고는 부서의 사용 승인이 확인되지 않았습니다.
- 공개 주소에서는 누구나 접속할 수 있고 AI 호출 비용이 발생합니다. 배포한 쪽에서 OpenAI 월 사용 한도와 Vercel 방화벽 속도 제한을 설정해야 합니다.
